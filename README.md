## 这一课解决什么

学生最常卡住的地方不是公式本身，而是两个问题：

1. **两个 q 不是同一个量**。定义式里的 q 是“这段时间过截面的全部电荷量”（1 C 上下），微观式里的 q 是“一个自由电荷的电荷量”（1.6×10⁻¹⁹ C）。教材两处都写小写 q —— 字母重名，不是规律矛盾。
2. **微观式不是另一条规律**，它是定义式 + 一个柱体模型的必然结果。课件里把两条路并排算，相对差恒为 0。

## 五幕 15 步

| 幕 | 步 | 干什么 |
|---|---|---|
| 第一幕 · 定义式 | 1–3 | 数过横截面的电荷量，拖时间看 Q–t 直线的斜率；三条变形与电流方向的规定 |
| 第二幕 · 微观式 | 4–7 | 四个微观量 n、q、S、v；柱体法 l = v·t → V = Svt → N = nSvt → Q = Nq → **I = Q/t = nqSv**（t 被约掉） |
| 第三幕 · 两式对账 | 8–11 | 两条路并排算，相对差 0.000000%；两个 q 的对照；混用会放大 10¹⁹ 倍；量纲自检 |
| 第四幕 · 真实量级 | 12–14 | 铜 n = 8.49×10²⁸ /m³、S = 1 mm²、I = 1 A → v = 0.074 mm/s；电子爬 1 m 要 3.78 h，电场只要 3.34 ns；变化电流时 I = Q/t 是平均值 |
| 第五幕 · 小结 | 15 | 一张卡片：定义式 + 柱体模型 = 微观表达式 |

## 怎么玩

- **拖「时间 t」**：电荷往右爬，横截面处累积的电荷量跟着涨，下方 Q–t 直线的端点同步走。
- **拖「定向速率 v」「数密度 n」「横截面积 S」**：微观幕里电荷跑多快、挤多密、导体多粗，都能直接看出来；右侧读数里 I = Q/t 与 I = nqSv 同时变。
- **点「负电荷 / 正电荷」**：电子往右跑，白色电流箭头却指向左边 —— 方向规定的可视化。
- **拖「电流 I」**：电子那条时间线在 1 s 到 1 天之间滑动，电场那条纹丝不动。
