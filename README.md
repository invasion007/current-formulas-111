# 11.1 电流的两条公式 · 可交互课件

人教版必修第三册 11.1《电源和电流》配套可视化：把 **定义式 I = Q/t** 与 **微观表达式 I = nqSv** 的推导过程做成可以拖着看的课件。

在线打开：<https://invasion007.github.io/current-formulas-111/>

## 这一课解决什么

1. **两个 q 不是同一个量**。定义式里的 q 是“这段时间过截面的全部电荷量”（1 C 上下），微观式里的 q 是“一个自由电荷的电荷量”（1.6×10⁻¹⁹ C）。教材两处都写小写 q —— 字母重名，不是规律矛盾。
2. **微观式不是另一条规律**，它是定义式 + 一个柱体模型的必然结果。
3. **控制变量法怎么落到画面上**：这是本课的主线（见下）。

## 主线：三步控制变量

| 控制变量 | 不变 | 只改 | 画面上看见什么 |
|---|---|---|---|
| ① 电流 | 时间 1 s、同一个横截面 | 电流 I | **亮黄色的那批电荷变多变少**：1 s 内过门的电荷，从 3 个一路数到 45 个 |
| ② 时间窗口 | 电流 | 时间 T | 截面后方那段柱体被拉长（l = v·T），能过门的电荷越来越多 |
| ③ 电荷密度 | 电流、时间、柱体长度 | 数密度 n | 同一根柱体里电荷变密 → 每层从 1 个变到 6 个，能过门的电荷变多 |

三个因素合起来就是 **I = n q S v**：柱体体积 V = S·v·T，里面 N = n·S·v·T 个电荷，每个带 q，合起来 Q = n q S v T，代回 I = Q/T，T 被约掉。

**“过门的电荷”是数出来的**：导体沿轴分 80 层，层距 0.1 mm，画面上亮黄色的就是 T 秒内会全部通过横截面的那批电荷。左上角的计数牌实时显示“已过 N 个 / 共 M 个”，点「▶ 播放」可以看着它们一个个过门。

## 五幕 16 步

| 幕 | 步 | 干什么 |
|---|---|---|
| 一 · 定义式 | 1–3 | 数过横截面的电荷量，拖时间看 Q–t 直线的斜率；三条变形与电流方向的规定 |
| 二 · 控制变量 | 4–8 | ① 只改电流 → 过门个数不同；② 任意时间 T → 柱体法；③ 电荷密度 n 浮现；④ 合成 I = nqSv |
| 三 · 推式与对账 | 9–12 | 两条路并排算（数出来的 = 算出来的，相对差 0）；两个 q 的对照；混用会放大 10¹⁹ 倍；量纲自检 |
| 四 · 真实量级 | 13–15 | 铜 n = 8.49×10²⁸ /m³、S = 1 mm²、I = 1 A → v = 0.074 mm/s；电子爬 1 m 要 3.78 h，电场只要 3.34 ns；变化电流时 I = Q/t 是平均值 |
| 五 · 小结 | 16 | 一张卡片：定义式 + 柱体模型 = 微观表达式 |

## 怎么玩

- **点「▶ 播放」**：电荷从 t = 0 跑到 T，看着它们一个个越过横截面，计数牌同步累加。
- **拖「电流 I」**：同样 1 秒里亮黄色的电荷变多变少 —— 控制变量①。
- **拖「时间窗口 T」**：截面后方那段柱体（黄色）跟着变长 —— 控制变量②。
- **点「电荷密度 n」**：把密度这一层浮现出来，再拖 n 看同一根柱体里电荷变密 —— 控制变量③。
- **点「自由电荷 / 那段柱体」**：可以分别隐藏，方便只讲一层。
- **点「负电荷 / 正电荷」**：电子往右跑，白色电流箭头却指向左边。
